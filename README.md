## 📂 Projects

### AXI4-Lite Crossbar Interconnect (RTL Design Project)

- Developed a modular crossbar micro-architecture with input skid buffers, address decoder, arbitration logic, and response routing blocks.
- Implemented dynamic address decoding to correctly route master requests to target slaves and handle illegal accesses.
- Designed fair read/write arbitration to prevent contention, starvation, and deadlock among multiple masters.
- Integrated skid buffers to manage backpressure and improve timing robustness under stall conditions.
- Built a per-master request tracking mechanism to preserve transaction context and ensure correct response ordering.
- Verified functionality using custom Verilog testbenches and detailed waveform analysis in Vivado XSim.
- Synthesized the design in Vivado, analyzing resource utilization and scalability trends with increasing masters/slaves.
